# NuBlox V1 brand assets — historical reference

This directory is retained as V1 implementation history and visual-reference material only.

The production NuBlox identity was superseded on 13 September 2026. The canonical source of truth is now:

```text
appv2/src/lib/assets/brand/nublox-logo.svg
```

with the governing production identity documented in:

```text
docs/branding/09-production-identity.md
```

The canonical NuBlox application typeface is **Noto Sans**.

Do not introduce new V2 dependencies on the SVG or WebP assets in this V1 directory, do not treat the earlier gradient/three-dimensional N mark as current production identity, and do not copy its typography into new product surfaces.

These files remain useful only for historical traceability of the earlier branding work.
