# UX and Information Architecture

**Status:** Compatibility reference  
**Canonical experience architecture:** [`architecture/bottom-up/layer-8-experience-workspaces.md`](architecture/bottom-up/layer-8-experience-workspaces.md)

NuBlox uses context-first workspaces composed over canonical records and domain commands. UI composition is deliberately an upper architecture layer: screens never define business authority, lifecycle or data identity.

Career/profession and project role may tailor relevance and terminology but do not grant permission. Navigation exposes recognisable business contexts rather than internal database/service boundaries. Derived visualisations remain projections over authoritative records.

Accessibility target: WCAG 2.2 AA.

New experience architecture belongs in Layer 8 rather than this compatibility path.
