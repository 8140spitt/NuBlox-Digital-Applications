# SAP Capability Coverage Register

The source register is [`sap-capability-coverage-register.csv`](sap-capability-coverage-register.csv).

**Important:** the CSV predates the 27 August 2026 World-Class NuBlox rebaseline. Its `E##` domain mappings and `target_slice` values are retained as historical provenance and are **not current delivery authority**.

Use [`world-class/11-sap-benchmark-coverage.md`](world-class/11-sap-benchmark-coverage.md) for the governing interpretation of the 64 SAP benchmark references against:

- the 19 native NuBlox capability domains;
- the nine enterprise value streams;
- the three golden reference journeys;
- the World-Class Capability Control Matrix; and
- current repository evidence.

SAP capability names are external benchmark labels, not NuBlox modules or architecture boundaries.
