# NuBlox Architecture Decision Records

Architecture Decision Records (ADRs) capture technical decisions that materially constrain implementation.

| ADR | Decision | Status |
|---|---|---|
| [ADR-0001](0001-database-query-and-migration-tooling.md) | Database query and migration tooling | Accepted |

## Rules

- ADRs are immutable decision history once superseded; add a new ADR rather than rewriting the rationale.
- A later ADR may explicitly supersede an earlier decision.
- Repository implementation should match accepted ADRs or record the reason for divergence.
