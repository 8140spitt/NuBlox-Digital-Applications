# Guide 04: Enterprise Search and Portal Sharing

## Purpose

Use this guide to find authorised records across NuBlox and control external collaboration through portal sharing.

## Preconditions

- You are signed in and have an active organisation context.
- You have required permissions for search and portal management.

## Procedure A: Search authorised records

1. Open **More** and select **Enterprise search**.
2. Enter a term in **Search term**.
3. Run search and review only authorised results.
4. Open a result to continue within its source workspace.

## Procedure B: Manage project sharing in portal

1. Open **Portal** and select **Manage sharing**.
2. Choose the target project from **Project**.
3. Use sharing cards to assign controlled work:
- RFI assignment
- Submittal review assignment
- Instruction recipient assignment
- Issued revision transmittal
4. Confirm recipient organisation appears in participant list.

- Enterprise search returns results scoped to your permissions.
- Portal sharing exposes only explicitly assigned work to participant organisations.
