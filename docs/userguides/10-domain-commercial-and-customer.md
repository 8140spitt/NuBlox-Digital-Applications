# Domain Guide: Commercial and Customer

This guide covers CRM, opportunities, estimates, quotations, purchasing, contracts, cost control, and valuations.

## A. Customers and Contacts (CRM)

1. Open the Customers workspace.
2. Select create to add an organisation or contact.
3. Complete required profile fields.
4. Save and confirm the record appears in the register.

![Figure 14 - CRM Customers](screenshots/14-crm-customers.png)

## B. Opportunities

1. Open Opportunities.
2. Select new opportunity.
3. Enter title, client, stage, and estimated value.
4. Save and verify pipeline status is visible.

![Figure 15 - CRM Opportunities](screenshots/15-crm-opportunities.png)

## C. Estimates

1. Open Commercial Estimates.
2. Create a new estimate.
3. Add scope assumptions and cost lines.
4. Save and verify estimate totals.

![Figure 16 - Commercial Estimates](screenshots/16-commercial-estimates.png)

## D. Quotations

1. Open Commercial Quotations.
2. Create or convert from estimate.
3. Review commercial terms.
4. Issue the quotation and track status.

![Figure 17 - Commercial Quotations](screenshots/17-commercial-quotations.png)

## E. Purchasing

1. Open Purchasing.
2. Create a procurement package.
3. Add requirements and supplier references.
4. Progress to order/commitment controls.

![Figure 18 - Purchasing](screenshots/18-purchasing.png)

## F. Contracts

1. Open Contracts.
2. Create or open a contract.
3. Maintain lifecycle updates and amendments.
4. Confirm latest contract state is recorded.

![Figure 19 - Contracts](screenshots/19-contracts.png)

## G. Project Cost Control

1. Open Project Cost Control.
2. Select project context.
3. Review commitments, forecast, and control totals.
4. Record approved commercial adjustments.

![Figure 20 - Project Cost Control](screenshots/20-project-cost-control.png)

## H. Valuations

1. Open Valuations.
2. Create valuation period entries.
3. Record progress/certified values.
4. Save and verify valuation status.

![Figure 21 - Valuations](screenshots/21-valuations.png)
