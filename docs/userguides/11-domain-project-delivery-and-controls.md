# Domain Guide: Project Delivery and Controls

This guide covers project setup, document control, project-level controls, and specialist delivery workspaces.

## A. Projects

1. Open Projects.
2. Create or open a project record.
3. Confirm project number, name, and status.
4. Enter project workspace to continue delivery controls.

![Figure 13 - Projects](screenshots/13-projects.png)

## B. Documents and Project Information

1. Open Documents.
2. Create controlled document records.
3. Progress RFI, submittal, and instruction flows.
4. Confirm current revision and status are visible.

![Figure 07 - Documents Workspace](screenshots/07-documents-workspace.png)

## C. Project Cost Control and Valuations

1. Open Project Cost Control from More or Commercial.
2. Select the project context.
3. Review control positions and record approved adjustments.
4. Open Valuations and complete valuation records.

![Figure 20 - Project Cost Control](screenshots/20-project-cost-control.png)
![Figure 21 - Valuations](screenshots/21-valuations.png)

## D. Site, Quality and Safety

1. Open Site, Quality and Safety.
2. Create/open site diary, quality inspection, or safety observation.
3. Record evidence and lifecycle updates.
4. Close out items with controlled status changes.

![Figure 25 - Site Quality Safety](screenshots/25-site-quality-safety.png)

## E. Project Search and Navigation

1. Use workspace Search to find delivery workspaces quickly.
2. Use More to reach specialist project functions.
3. Keep project context active while moving across workstreams.

![Figure 04 - Workspace Search](screenshots/04-workspace-search.png)
