# NuBlox Complete Application Guide (Step by Step)

This guide covers each major application area with direct steps, figure references, and label maps.

1. Open the sign-in page.
2. Enter Email and Password.
3. Select Sign in.
4. Select your organisation from the context chooser.

## Usage notes

- Permissions determine visibility of workspaces and actions.
- Keep project context pinned where available when switching business functions.
- Controlled records should be progressed through their lifecycle states, not overwritten informally.
